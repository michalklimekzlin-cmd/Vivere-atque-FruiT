# CHT 360°‰ User Guide

## Co je CHT 360°‰

Místní sada PWA modulů pro paměť, glyphy, mluvu, bubínky, signály a pracovní jádra.

## Jak se pohybovat

- Horní shell vždy drží `Zpět`, `Domů`, breadcrumb a rychlé moduly.
- Spodní shell drží stav modulu, rychlou cestu do ChybaŽrouta a ladění.
- `Escape` zavře otevřený panel nebo modal.

## Běžné workflow

1. Založ nebo uprav paměť v hlavním CHT.
2. Přejdi do Glyphů nebo Bubínků přes rychlé moduly.
3. Sleduj toast potvrzení po důležité akci.
4. Když se data změní v jiné kartě, shell ukáže stav synchronizace.

## Kde hledat pomoc

- Tlačítko `? Pomoc` v horní liště
- Tlačítko `ChybaŽrout` ve spodní liště
- Debug/Ladění pro logy a poslední měření
