# CHT 360°‰ Design System

## Barevné tokeny

```css
--cht360-gold-primary: #e7b65c;
--cht360-gold-light: #f5e6c8;
--cht360-gold-dark: #b8933c;
--cht360-bg-primary: #fafaf8;
--cht360-bg-secondary: #f0ede6;
--cht360-text-primary: #2a2a2a;
--cht360-text-secondary: #666666;
--cht360-border: #d4cfc5;
--cht360-success: #4caf50;
--cht360-error: #f44336;
--cht360-warning: #ff9800;
--cht360-info: #2196f3;
--cht360-cream: #fff0d3;
```

## Typografie

- Nadpisy: 32 / 28 / 24 / 20 px
- Text: 16 px
- Drobný text: 14 px
- Monospace/debug: 14 px
- Řádkování: 1.5 text, 1.2 nadpisy

## Spacing

Používej kroky: `4, 8, 12, 16, 24, 32, 48, 64 px`.

## Sdílené vzory

- Globální shell: zpět, domů, breadcrumb, stav synchronizace, rychlé moduly
- Toasty: potvrzení, varování, chyba
- Dialogy: pomoc a ladění
- Dotykové cíle: minimálně 44 px výška

## Ikony

- Navigace: `←`, `⌂`, `?`
- Stav: barevná tečka
- Modulové štítky: krátký badge názvu modulu

## Showcase

Sdílené chování drží `docs/js/cht-ui-components.js` a používá konfiguraci z `docs/js/cht-360-config.js`.
